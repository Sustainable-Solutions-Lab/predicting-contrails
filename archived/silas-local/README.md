# silas-local

Silas Whiteson's original laptop-side scripts, relocated here from the
lab Dropbox (`WS Corp contrails (w Silas)/Analysis/`) on 2026-08-17 so
that all code lives in this git repo and the Dropbox holds only data,
outputs, and manuscript/figure files.

- `Flights.py`, `finalcolumns.py` — original data-prep that assembled
  the process-model dataset and engineered features (June 2024).
- `warmingmap.py` — laptop variant of the Fig 1 warming-map script,
  with `/Users/silas/...` paths; differs from the Sherlock variant in
  `../sherlock-snapshot/warmingmap.py`.

Kept for traceability; superseded by the scripts in `experiments/` and
`figures/`.
